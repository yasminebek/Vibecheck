# Contributing

Keep analysis local and permissions minimal. New rules must state what was observed, distinguish heuristics from confirmed failures, include a suggested fix and acceptance check, and document coverage limits. Do not collect page text, input values or secrets in reports. Render page-derived data as text, never HTML.

Open an issue describing the problem and reproduction on a public demo or minimal fixture. Avoid posting private URLs or screenshots. For changes, add focused broken and healthy cases, run the tests in README, and describe any permission or privacy change explicitly. Do not add remote runtime scripts.
