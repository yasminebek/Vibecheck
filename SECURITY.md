# Security

This extension is a page-quality helper, not a vulnerability scanner or security certification. Only inspect sites you are entitled to access. It does not bypass access controls or actively probe servers.

Do not post credentials, private reports or exploit details in public issues. For vulnerabilities in this extension, use GitHub private vulnerability reporting if the repository owner has enabled it. Otherwise request a private contact channel without publishing sensitive details.

The publisher should enable private vulnerability reporting in repository settings before inviting security reports.
