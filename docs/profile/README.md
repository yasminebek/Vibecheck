## Featured project

### [VibeCheck](https://github.com/yasminebek/Vibecheck)

A local-first Chrome and Brave extension that inspects a live webpage and turns observable issues into an actionable prompt for a coding agent.

- Structured findings with evidence, suggested fixes and acceptance checks.
- Deterministic prompt generation: no LLM calls, account or API key.
- User-initiated page access with minimal browser permissions.
- Unit and browser tests, real-extension integration coverage, and GitHub Actions CI.
- Open source under the MIT license; currently an initial developer release.

[Explore the code](https://github.com/yasminebek/Vibecheck) · [Installation and scope](https://github.com/yasminebek/Vibecheck#install-in-desktop-chrome-or-brave)
